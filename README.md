## О практике

Придумываем программный проект (10–15 юз кейсов), выбираем концепцию формальными
методами принятия решений, оцениваем объём и трудозатраты, строим календарный план
с ограниченными ресурсами. Фазы 2 и 4 - мета: там объектом планирования становится
наша собственная работа по фазам 3 и 5.

## Фазы

| Фаза | Папка | Содержание |
|---|---|---|
| 1. Выбор концепции | `phases/phase1/` | ≥4 концепции и ≥4 критерия, трёхточечные экспертные оценки, выбор варианта нечётким коллективным TOPSIS и чётким коллективным МАИ, сравнение результатов |
| 2. Распределение работы (мета) | `phases/phase2/` | декомпозиция работ фазы 3, экспертная оценка сложности, индивидуальные предпочтения, постановка и решение задачи распределения |
| 3. Оценка проекта | `phases/phase3/` | ≥10 Use Cases, оценка в COSMIC FP и Use Case Points, коллективная экспертная оценка, выводы о масштабе, составе команды и сроке |
| 4. Прогнозирование (мета) | `phases/phase4/` | декомпозиция работ фазы 5, трёхточечные оценки, две модели Монте-Карло (по числу задач за неделю и по трудозатратам), срок с 80% достоверностью |
| 5. Планирование | `phases/phase5/` | 20–25 задач проекта, состав команды как типы ресурсов, ресурсные требования и связи предшествования, перебор эвристик упорядочения, календарный план на 40-часовую неделю |

Порядок выполнения: **1 → 2 → 3 → 4 → 5**.
